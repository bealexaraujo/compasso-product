# Metrics

## North Star Metric

**Monthly Obligation Completion Rate** — the percentage of obligations due in a given month that the user completes on time, across all active users.

This metric captures the core product promise: Compasso exists to ensure professionals never miss a fiscal deadline. If this number is high and growing, the product is working. If it drops, something is broken (in the agent, the onboarding, or the user experience.)

Target: ≥ 90% completion rate for users who have been active for 3+ months.

## Retention Metric

**3-Month Consecutive 100% Rate** — the percentage of users who complete 100% of their obligations for three months in a row.

Fiscal compliance is annual. A user who misses obligations in month 4 has already failed the product's core promise. The 3-month streak signals that Compasso has become a habit, not a novelty.

This also drives the streak mechanic visible in the dashboard ("Sequência: 3 meses seguidos com 100%"). It's not just a gamification element, it's the retention metric made visible to the user.

## Fines Avoided (Value Metric)

**Cumulative fines avoided (R$)** — the total amount in penalties the user would have paid if they had missed their deadlines, displayed in the dashboard.

This metric does two things:
1. It's a direct measure of financial value delivered. One of the few SaaS products where you can show the user exactly how much money you saved them.
2. It creates emotional engagement. Seeing "R$ 227,50 in avoided fines" makes the product feel concrete. The user isn't paying R$24,90/month for reminders, they're paying to avoid R$227,50 in fines.

## Acquisition Metrics

| Metric | Description |
|---|---|
| Trial starts | Users who begin the 7-day free trial |
| Trial → Paid conversion | % of trials that convert to a paid plan |
| Time to first obligation completed | How quickly new users complete their first obligation after onboarding |

The key acquisition insight: a user who completes their first obligation within 7 days of signing up is significantly more likely to convert. Onboarding should be designed to manufacture that moment.

## Engagement Metrics

| Metric | Description |
|---|---|
| Agent interactions / month | WhatsApp messages exchanged per active user |
| Document upload rate | % of obligations completed via document upload vs. manual confirmation |
| Dashboard opens / month | How often users check their Compasso panel |

Dashboard opens are a weak signal. The product is designed to work without the user opening the app. If dashboard opens are high, it may mean the agent isn't doing its job. If they're very low, it may mean the user has disengaged entirely.

## What We Are Not Measuring (and Why)

**Daily Active Users (DAU):** Compasso is not a daily-use product. A professional with 4 monthly obligations should interact with Compasso 4 times a month, not daily. DAU would systematically undervalue a product working exactly as designed.

**NPS in isolation:** Net Promoter Score is useful for directional feedback, but a user can love the product and still not recommend it (fiscal compliance is not a common dinner table topic). Retention and completion rate are better proxies for satisfaction.

**Feature usage breadth:** The product has one job. A user who only uses the obligation tracking and ignores the blog content is not an underperforming user, they're an efficient one.
